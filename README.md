Control your system volume using hand gestures via webcam — no touch required!

## ✨ Features
- 🎯 Real-time hand tracking
- 🔊 Volume control using finger distance
- 📷 Works with any webcam
- ⚡ Fast and lightweight

## 📁 Project Structure
├── main.py
├── HandTrackinModule.py
├── VolumeHandControl.py
└── README.md

## ⚙️ Installation
pip install opencv-python mediapipe numpy pycaw comtypes

## ▶️ How to Run
python main.py

## 🖐️ How to Use
- Show your hand to the webcam
- Thumb + Index finger **apart** = Volume UP 🔊
- Thumb + Index finger **close** = Volume DOWN 🔇
